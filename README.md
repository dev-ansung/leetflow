# LeetFlow (VS Code Extension)

Intelligent, adaptive LeetCode practice companion with local test runners and spaced repetition.

## Features
- **Adaptive Practice**: Recommends the next optimal problem based on topic Elo and spaced repetition.
- **Side-by-Side Webview**: View problem statement, examples, constraints, and hints in your editor.
- **Local Test Runner**: Run sample test cases in <100ms with colorized visual diffs.
- **Progress Tracking**: Tracks solve speed, zero-shot accuracy, and cognitive friction.

## Commands
- \`LeetFlow: Next Recommended Problem\` (\`leetflow.next\`)
- \`LeetFlow: Run Tests\` (\`leetflow.test\`)
- \`LeetFlow: Submit Solution\` (\`leetflow.submit\`)
- \`LeetFlow: View Stats & Mastery\` (\`leetflow.stats\`)
